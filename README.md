## Correction impérative
La formule **Annulé et Nul** est exactement :

**(C1.a) + (1.c) + (1.d)**

Elle est appliquée dans la colonne correspondante du tableau LIMITES.

**(C1.a) + (C3.c) + (C4.d)**

## UX
Le design premium V14 est conservé avec une couche cinématique légère :
- balayage lumineux du stade ;
- halo/stade animé ;
- ballon flottant ;
- apparition progressive des cartes ;
- balayage lumineux du bouton principal ;
- micro-animation des résultats ;
- respect de `prefers-reduced-motion`.

Aucune formule non explicitement demandée n'a été modifiée.
