# Betru V14 — Single Model Football Cinematic Final

Version de déploiement finale orientée mobile.

- Un seul modèle.
- Design football cinématique léger (CSS/SVG, sans dépendance externe).
- Logo Betru : football + couronne + B + flèche de progression.
- Icônes Android PNG 192x192 et 512x512 + SVG.
- `worker.js` conservé pour les calculs lourds.
- `config.json` conservé pour les règles mathématiques.
- Les formules de calcul ne sont pas modifiées par le redesign.
- La formule « Annulé et Nul » reste `(C1.a)+(1.c)+(1.d)`.
- La formule « Nul » reste `(C1.a)+(C3.c)+(C4.d)`.
- Aucun ancien sélecteur de modèle n'est affiché.
