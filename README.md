# Betru V14 — Single Model Final

Cette version reprend l'interface de référence actuelle :
- un seul modèle ;
- CAI — Capital initial ;
- p — Pourcentage ;
- NUL_X — C1 ;
- VICTOIRE_12 — C2 ;
- REMBOURSESINUL_1 — C3 ;
- REMBOURSESINUL_2 — C4 ;
- Résultats principaux ;
- Limites ;
- Règles limites ;
- SIMEU ;
- Estimation de l'itération ;
- Fond de jeu.

Les anciens éléments de l'interface à deux modèles ne sont plus affichés :
- V1 · R1 · V2 · R2
- X · 12 · R1 · R2
- sélecteur « Modèle de jeu »
- ancienne navigation
- ancien écran hero/premium.

La formule « Annulé et Nul » reste exactement :
(C1.a) + (1.c) + (1.d)

La formule « Nul » reste :
(C1.a) + (C3.c) + (C4.d)

Le pourcentage p est maintenant une saisie visible et est utilisé directement dans le calcul.
