# Betru V11.2
Version mono-page basée sur BETRU_GUIDE(1).docx.

Fichiers:
- index.html : interface complète mono-page.
- worker.js : moteur de calcul non bloquant.
- config.json : configuration des coefficients, règles et formules.
- sw.js : cache PWA.
- manifest.webmanifest / icon.svg : PWA.

Les libellés, formules LIMITES, SIME/SIMEU, Estimation d'itération et Fond de jeu suivent le document fourni.
Les résultats numériques sont calculés dynamiquement; aucun résultat d'exemple n'est codé en dur.
