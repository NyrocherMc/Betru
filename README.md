# Betru
Application mobile web/PWA basée sur `BETS_RULES.xlsx`.

## Utilisation Android
1. Héberger le dossier `app` sur un hébergement HTTPS (Vercel, Netlify, GitHub Pages, etc.).
2. Ouvrir l'adresse dans Chrome Android.
3. Choisir **Installer l'application** / **Ajouter à l'écran d'accueil**.

## Règles
Les deux modèles, formules, arrondis, mises retenues, scénarios de résultats et bénéfice minimum sont reproduits depuis le fichier Excel source.
